Mô Tả Nội Dung LAB_1.2: Thiết lập hai máy Linux cùng mạng, cài đặt và cấu hình Telnet, SSH. Thực hiện kết nối giữa máy khách và máy chủ, sau đó dùng Wireshark để bắt và phân tích các gói tin.
Kết quả thực hiện: Kết nối Telnet và SSH thành công, bắt được các gói tin trên Wireshark. Qua phân tích thấy Telnet có thể đọc được nội dung trao đổi, còn SSH đã mã hóa nên an toàn hơn.
