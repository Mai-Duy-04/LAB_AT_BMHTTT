Nội Dung Đã Thực Hiện: Cấu hình mạng Host-Only cho Kali Linux và Windows Server 2025, kiểm tra kết nối giữa hai máy, cài đặt Nmap và thực hiện các kiểu quét như Host Discovery, TCP, SYN, FIN, Xmas, NULL, ACK, UDP, nhận diện dịch vụ, hệ điều hành và kiểm tra SMB bằng NSE.
Kết Quả Thực Hiện: Hai máy kết nối được trong cùng mạng Host-Only. Nmap phát hiện được các host đang hoạt động, xác định cổng 5985/tcp đang mở, nhận diện dịch vụ Microsoft HTTPAPI và hệ điều hành thuộc họ Windows. Cổng SMB 445/tcp ở trạng thái filtered và đã lưu được kết quả quét ra file nmap_result.txt.
