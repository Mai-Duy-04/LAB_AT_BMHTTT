Nội Dung Đã Thực Hiện: Đã cấu hình các website mô phỏng trên Ubuntu Server, thiết lập DNS trên DC01 và cài đặt Squid, E2Guardian, ClamAV. Đồng thời, cấu hình và kiểm thử các chính sách Hard Block, Warning, Allow thông qua Web Proxy.
