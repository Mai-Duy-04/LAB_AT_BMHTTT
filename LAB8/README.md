Nội Dung Đã Thực Hiện:Cấu hình mạng DNSLAB trên pfSense, thiết lập DNS-SERVER bằng BIND9, cấu hình Kali Linux và mô phỏng máy Victim. Thực hiện thay đổi file hosts, kiểm tra phân giải tên miền, bắt gói tin DNS bằng tcpdump và thiết lập AUTH-DNS mô phỏng. 
Kết Quả Thực Hiện: Các máy trong mạng DNSLAB kết nối và phân giải tên miền thành công. Task 1 thực hiện đúng yêu cầu, Kali bắt được gói truy vấn và phản hồi DNS, AUTH-DNS trả lời với độ trễ 1,5 giây. Phần DNS Spoofing và Cache Poisoning chưa hoàn thành kiểm thử.
