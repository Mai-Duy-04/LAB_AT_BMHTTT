Nội Dung Đã Thực Hiện: Trong bài thực hành Lab 2, đã xây dựng chương trình mã hóa đối xứng hiện đại bằng ngôn ngữ Java trên Apache NetBeans, bao gồm 5 thuật toán DES, TripleDES, AES, RC4 và Twofish. Chương trình được thiết kế giao diện bằng Java Swing, hỗ trợ mã hóa, giải mã, lưu và mở tệp văn bản. Ngoài ra, chương trình còn tích hợp chức năng đăng ký, đăng nhập và tạo Ticket cho AES, kết nối SQL Server để lưu trữ thông tin tài khoản, lịch sử hoạt động và xây dựng Menu chính để quản lý các chức năng.
Kết Quả Thực Hiện: Chương trình đã được xây dựng và kiểm thử thành công các chức năng mã hóa, giải mã của 5 thuật toán theo yêu cầu thực hành. Các chức năng lưu, mở tệp văn bản, đăng ký, đăng nhập và kết nối SQL Server hoạt động đúng. Thông tin tài khoản và lịch sử mã hóa, giải mã được lưu trữ và truy xuất trên cơ sở dữ liệu. Giao diện Menu chính cho phép người dùng truy cập các chức năng thuận tiện, chương trình được biên dịch và chạy thành công trên Apache NetBeans.
